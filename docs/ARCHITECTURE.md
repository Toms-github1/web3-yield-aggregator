## 数据流

### 1. 产品发现流程
```
用户访问产品列表
  ↓
前端请求 /api/products?chain=ethereum&type=yield
  ↓
后端查询缓存 (Redis)
  ↓
如果缓存未命中，聚合服务从多链 RPC 和 API 爬取最新产品
  ↓
返回产品列表（包括 APY、TVL、风险评分）
  ↓
前端展示并排序
```

### 2. 实时收益更新
```
每 5 分钟：后台任务更新 APY 数据
  ↓
Redis 缓存更新
  ↓
WebSocket 推送客户端
  ↓
前端实时刷新图表
```

### 3. AI 策略推荐
```
用户输入投资金额和风险偏好
  ↓
后端发送请求到 FastAPI 聚合器
  ↓
Python 算法计算最优配置（风险-收益模型）
  ↓
返回推荐策略和预期 APY
  ↓
用户可以一键执行或自定义调整
```

## 核心模块

### 前端 (Next.js)
- `pages/` - 页面路由
- `components/` - React 组件
- `hooks/` - 自定义 hooks（Web3 集成）
- `services/` - API 客户端和工具
- `store/` - Zustand 状态管理

### 后端 (Express)
- `routes/` - API 路由定义
- `controllers/` - 业务逻辑
- `models/` - 数据模型和 ORM
- `services/` - 数据处理服务
- `middleware/` - 认证、日志等

### 聚合器 (FastAPI)
- `aggregators/` - 各协议数据爬取器
- `strategies/` - 收益优化策略算法
- `risk/` - 风险评估模块
- `cache/` - 缓存和同步逻辑

## 扩展性考虑

- **微服务架构**：未来可以将聚合器、风险评估等拆分为独立服务
- **消息队列**：使用 RabbitMQ/Kafka 解耦服务
- **CDN**：前端资源和 API 响应缓存
- **地理分布**：在不同地区部署 RPC 节点和后端实例
